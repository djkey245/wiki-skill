# wiki-skill

[`wikipedia-interest/`](wikipedia-interest/) is an [Agent Skill](https://agentskills.io/specification)
that analyses interest in topics from Wikipedia pageviews across language editions and prepares
charts and a one-page PDF report. Everything that belongs to the skill (code, references, tests,
evals) lives in that directory; start with its [README](wikipedia-interest/README.md).
